# Contributing

Create a local disposable database using the README, then run lint, typecheck, unit tests, integration tests and a production build. Run browser tests against that isolated database. Never use real users or credentials as fixtures. Use reserved `example.test` addresses.

Changes to booking/notification concurrency need PostgreSQL integration coverage. Keep Swedish UI wording and Europe/Stockholm date semantics. Read the installed Next.js guide in `node_modules/next/dist/docs/` before changing framework code.

Submit focused pull requests with the problem, resulting behavior and validation. Contributions are under the MIT license. Preserve third-party notices. Report vulnerabilities privately as described in SECURITY.md.
